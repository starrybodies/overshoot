# OVERSHOOT source and acquisition register

Reviewed 22 September 2026. This is a record of tested acquisition paths, existing imports and remaining blockers. Public access, permission to redistribute, and integration into the app are separate questions. No scheduled refresh is running.

## Refresh and quality method

1. Acquire official machine-readable files into a candidate directory. Record the request URL, retrieval time, content hash and release identifier. Never replace a working release with an error page.
2. Check the source licence and any third-party exceptions. Retain exact dimensions, source units, geography, flags and null markers.
3. Normalize only explicitly defined quantities. Do not convert energy content to physical tonnes, infer metal content from ore mass, sum daily rates, or combine overlapping categories.
4. Reject duplicate country/measure/period keys and unexpected schema or unit changes. Compare revisions, geographic coverage and maximum reporting period with the published release. Source zeros remain zeros; absent or non-numeric values remain missing.
5. Check representative countries against their original series and cross-check only definition-compatible sources. Record unexplained disagreements instead of averaging them away.
6. Publish a versioned, validated snapshot. Show the reporting period, acquisition date, source, unit and limits in the app. Failed imports preserve the previous release.

## What is still missing

Mineral-specific mine/refinery output, global LNG partner routes, current field-level throughput and universal local waste destinations are not supplied by the new energy tables. USGS acquisition, BGS republication rights, JODI gas export access and GEM asset exports need further work. Climate TRACE can add emissions context, not a substitute material-flow total. The existing trade map remains a selected reporter sample.
